# data/ 目录说明

本目录按课程要求的 Raw Data → Cleaned Data → Integrated Data 三层组织，是仓库内唯一的数据树（问题一代码通过 `支撑文件/问题一/lib/paths.py` 的 `DATA` 根指向此处）。

## 四类核心数据

1. **行政处罚数据**：用于刻画广东省土地违法行政处罚的案件特征。
2. **裁判文书数据**：用于分析行政机关申请人民法院强制执行后，法院是否准予执行及其裁定理由。
3. **广东土地覆盖与建设用地数据**：提供年度土地覆盖和建设用地变化背景（CLCD，30 m，1990—2025）。
4. **案件遥感影像数据**：用于观察具体地点处罚前后的地表变化，为执行情况核查提供线索（Sentinel-2 / Landsat）。

法律法规和新闻政策仅作解释背景，不列入四类核心数据。

## 目录与内容

| 目录 | 内容 | 与原始交付包的对应 |
|---|---|---|
| `raw/` | 四类数据的代表性原始样本（处罚原文 10 份、裁判文书 10 份、遥感对比图 3 组、土地覆盖 1990/2015/2025 三期），另含两张**代码直接读取的完整源表**（处罚明细、处罚—裁判关联表） | 原 `01_Raw_Data_Samples`，并入原 `支撑文件/问题一/data/raw` 的两张源表 |
| `cleaned/` | 清洗、标准化后的完整结构化表：处罚 20,970 行 × 17 字段、文书 11,186 行 × 14 字段，以及建设用地初步分析与变化检测指标 | 原 `02_Cleaned_Data` |
| `integrated/` | 跨源融合结果：处罚—裁判关联表 3,407 条 × 28 字段；问题一证据台账 5 张（申请事件与间隔、S1 义务组合、S2 司法申请事件证据、确认关联处罚分类、逐项处罚义务与申请事项） | 原 `03_Integrated_Data` + 原 `支撑文件/问题一/data/integrated` |

> `raw/` 下的 `广东省土地违法行政处罚数据.xlsx` 与 `广东省土地违法行政处罚与裁判文书关联表.xlsx` 同时出现在 `cleaned/` 与 `integrated/` 中，是**代码输入副本**：问题一脚本按 `SOURCE = data/raw` 直接读取这两张表，重跑时以它们为起点重建证据台账；`cleaned/`、`integrated/` 下的同名文件为交付口径的正式版本。两处内容一致，SHA-256 见仓库根 `checksums.sha256`。

## 库外数据

原始归档（19,833 份处罚原文全文、1,070 份裁判文书、CLCD 完整 36 期约 680 MB、遥感影像堆栈）按课程「不需要上传完整数据」的要求未入库，重建路径见仓库根 `data_sources.md` 第五节。

## 使用边界

遥感影像反映的是地表变化线索，不能单独等同于违法建筑已经拆除或法院裁定已经执行完毕；有关执行结果仍需结合执行文书、行政机关记录或现场核查判断。CLCD 不透水面（编码 8）是地表硬化观测结果，不等于批准的建设用地。
