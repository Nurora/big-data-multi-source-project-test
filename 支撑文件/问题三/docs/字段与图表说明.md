# 核心字段与图表说明

## 核心结果表

逐案跨源整改核查.csv每行对应一个唯一地点，保留原序号、位置、区域、处罚日期、目标核查日期和实际前后影像日期。原人工判读是源指标表标签；跨源核查结果结合原标签与监测圆净变化形成，属于观察证据分类，不是新的结案判定。

S2新增：前非建成、后建成；S2减少：前建成、后非建成；净变化=新增−减少。CLCD新增与减少分别为编码8不透水面的进入与退出。面积单位均为m²，以10米对照网格像元数×100计算。

新增像元按CLCD四种状态转移分组：非8→8、8→8、非8→非8、8→非8；减少像元同理分为8→非8、8→8、非8→非8、非8→8。四组之和分别等于S2新增、减少总面积。两源同步减少仅表示两个分类代理在相同对照像元的减少，不直接等于建筑或违法用地拆除。

逐期空间关联.csv分为共同建成、仅S2建成、仅CLCD不透水、共同非建成；IoU=共同建成/(前三项之和)。监测范围敏感性.csv记录150/200/250米圆的差异比例，分母为各半径前后共同有效面积。

## 图表

图1展示原目视初判去重统计；图2展示同一监测范围的新增、减少和净变化；图3以7个典型地点展示前后真彩色和两源变化位置，其中包括全部5处疑似拆除；图4逐案汇总原标签与数值结果。四类图共5幅，PNG用于报告，SVG用于放大和排版。

## 网格

cleaned/aligned中每地点一个六波段uint8 GeoTIFF：1 S2前期建成候选、2 CLCD前期地类、3 前期有效掩膜、4 S2后期建成候选、5 CLCD后期地类、6 后期有效掩膜。建成与有效掩膜为0/1；分类波段0为无效，1—9为CLCD类别。不同波段含义不同，因此不统一设0为nodata，以有效掩膜控制统计。CRS为EPSG:32649。
