# 广东省土地违法执法与司法关联研究

《大数据原理与应用》课程中期大作业 · 多源多维度数据采集、融合分析与可视化

本仓库提交：**可复现代码 + 代表性样本 + 完整元数据与规模摘要 + 文件清单与 SHA-256 校验值**。
2 GB 级原始归档（19,833 份处罚原文全文、1,070 份裁判文书、36 期省级栅格、301 个遥感影像文件）按课程要求不下发仓库，以「样本 + 索引 + 校验值 + 采集脚本」替代，可据此回溯到原始归档。

---

## 1. 研究问题

围绕**土地违法从行政处罚到法院强制执行、再到地表实际变化**这一条可验证的链条，提出三个核心问题：

| 编号 | 核心研究问题 | 依赖数据源 |
|---|---|---|
| 问题一 | 广东省非法占用土地行政处罚案件在处罚主体、违法行为、地类用途、时间与义务结构上呈现什么特征？进入司法程序的案件在整个处罚—申请—裁定链条上如何分布？ | 行政处罚结构化表 + 处罚—裁判关联表 |
| 问题二 | 哪些处罚案件进入非诉执行审查后被准予或不准予执行？处罚端与裁判端的特征能否用于识别高风险案件？ | 行政处罚结构化表 + 裁判文书结构化表 |
| 问题三 | 法院裁定准予执行后，涉案地块是否发生实际地表变化？ | 裁判文书 + Sentinel-2/Landsat 影像 + CLCD 土地覆盖 |

三个核心问题各自由**两个及以上相互独立的数据源**共同支撑。仅按地市统计处罚数量一类的单源分析只作探索与辅助证据，不计入核心问题。

## 4. 快速开始

```bash
python -m pip install -r 支撑文件/问题一/requirements.txt

# 问题一：处理 → 分析 → 可视化 全链（约 1—3 分钟）
python 支撑文件/问题一/run_all.py

# 只看后半段（跳过 4.1 基础画像）
python 支撑文件/问题一/run_all.py --skip-profile

# 问题三（需先 pip install -r 支撑文件/问题三/requirements.txt，并具备原始压缩包）
python 支撑文件/问题三/run.py --extract --source-dir <原始压缩包所在目录>
```

产出写入 `支撑文件/问题一/output/tables/`（统计表）与 `output/figures/`（图表），该目录已在 `.gitignore` 中忽略。
数据根可用环境变量覆盖：`REPORT_DATA=/path/to/data python 支撑文件/问题一/run_all.py`。

## 7. 数据使用边界与许可

- 行政处罚决定书与裁判文书均为政府行政执法公示、司法公开渠道的**已公开文本**，仅用于课程研究，不在本仓库二次分发全文（仅保留少量样本用于核对字段提取结果）；样本未包含身份证号、住址、联系方式、银行账户等字段。
- CLCD 中国年度土地覆盖数据：武汉大学杨杰、黄昕团队，Zenodo 记录 18180184，v1.0.5，**CC BY 4.0**；使用编码 8（不透水面），沿用原投影与分类。
- Sentinel-2 L2A：Copernicus 数据，经 Microsoft Planetary Computer 获取；Landsat C2 L2：USGS 公开数据；OSM：**ODbL**。
- 采集过程遵守 robots 规则与访问频率限制，未绕过登录、付费墙或验证码；裁判文书检索通过机构订阅数据库的公开检索功能完成，未批量抓取受限内容。

> **结论边界**：遥感影像反映的是地表变化线索，不能单独等同于违法建筑已拆除或裁定已执行完毕；执行状态需结合执行文书、行政机关记录或现场核查判断。
