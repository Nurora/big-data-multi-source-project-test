# 数据处理流程

1. **Raw Data**：保留行政处罚原文、裁判文书原文、年度土地覆盖栅格和案件前后时点影像。
2. **筛选**：围绕土地违法、非法占地和违法建设等主题筛除与研究范围无关的记录。
3. **结构化**：从行政处罚和裁判文书中提取案件标识、主体、时间、地点、违法事实、裁定理由和裁定结果等字段。
4. **规范化与质检**：统一日期、地区、主体名称、文号和结果类别；检查缺失值、重复值、字段格式和异常值。
5. **关联**：优先依据处罚决定文号连接行政处罚与裁判文书，并以当事人、时间和地区辅助复核。
6. **空间补充**：以年度土地覆盖数据说明宏观土地利用背景，以案件前后时点影像观察地表变化。
7. **研究使用**：行政处罚数据支持案件画像；裁判文书及关联表支持强制执行监督模型；遥感结果仅作为执行情况核查线索。
